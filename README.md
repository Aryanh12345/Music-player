# 🎵 Music Player

A simple and interactive **Music Player** built using **HTML, CSS, and JavaScript**.

This project provides a clean music-player interface with playback controls and a visually appealing design for playing audio directly in the browser.

## 🌐 Live Demo

👉 **[Visit Music Player](https://aryanh12345.github.io/Music-player/)**

## 🚀 Features

- 🎵 Play and pause music
- ⏭️ Next track control
- ⏮️ Previous track control
- 🎚️ Music progress bar
- 🔊 Audio playback controls
- 🖼️ Album/track artwork
- 🎨 Clean and modern interface
- 📱 Responsive design
- ⚡ Lightweight and fast
- 💻 Built using pure HTML, CSS, and JavaScript

## 🛠️ Technologies Used

- **HTML5** – Music player structure
- **CSS3** – Styling, layout, and animations
- **JavaScript** – Audio controls and player functionality
- **HTML5 Audio API** – Playing and controlling audio
